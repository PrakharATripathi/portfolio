SmartTutor App Overview
SmartTutor is a Next.js application for JEE/NEET exam preparation with these key features:

AI-powered quizzes that generate personalized questions based on student needs
Streak tracking system to encourage consistent learning habits
Performance analytics with detailed reports on subject strengths/weaknesses
AI learning assistant for answering student questions

Technologies Used
Built with Next.js, MongoDB, TypeScript, and Tailwind CSS. Deployed on Vercel with NextAuth for authentication.
